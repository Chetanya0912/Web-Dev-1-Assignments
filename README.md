# Personal Portfolio Website

A simple, single-page portfolio website built with HTML. It introduces me, shows my projects and skills, and includes a contact form.

## Features

- Semantic HTML structure using `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`
- Navigation menu that scrolls to each section (Home, About, Projects, Skills, Contact)
- Hero section with a welcome message
- About section with a profile picture and short bio
- Projects section with short descriptions
- Skills table showing technical skills and proficiency levels
- Contact form with labeled fields (Name, Email, Message), placeholders, and required validation

## How to Run

1. Download or clone this project.
2. Make sure your photo is saved as `images/profile.jpg`.
3. Open `index.html` in any web browser.

If you use VS Code, you can also right-click `index.html` and choose **Open with Live Server**.

## Page Sections

| Section  | Description                                   |
|----------|-----------------------------------------------|
| Home     | Welcome message and short introduction        |
| About    | Profile picture and bio                       |
| Projects | List of sample projects with descriptions     |
| Skills   | Table of technical skills and levels          |
| Contact  | Form to send a name, email, and message       |

## Notes

- The contact form uses `action="#"`, so it does not send data anywhere yet. To receive real messages, connect it to a backend or a form service.
- All navigation links use anchor IDs (for example, `#about`), so they scroll to the matching section on the same page.
